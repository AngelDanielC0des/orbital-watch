# T13 — Wrap sky, solar, galaxy, satellites and track as `ILayer`s
Tier: sonnet55-high · Wave: 5 · Depends: T11

**Target**: new `src/engine/layers/{sky,solar,galaxy,satellites,track}-layer.ts`; `src/engine/layers/registry.ts` (add entries); `src/engine/create-engine.ts` (replace direct `new Sky/SolarSystem/Galaxy/SatelliteLayer/OrbitTrack` with `layers.register(...)` and `layer.inner` references; per-frame `update` calls move into `layers.update(ctx)` where the signature allows, otherwise stay explicit with a comment).
**Change**: one wrapper per renderer copying K4 exactly: `id`, `name`, `object3d = inner.group|object3d`, `visible`, `init` (async texture loads: `sky.load`, `solar.loadTextures`, lazy `galaxy`), `update(ctx)` mapping `LayerUpdateContext` to the renderer's own `update(...)` signature, `setVisible`, `setDetail`, `setViewport`, `dispose`. Expose `readonly inner` for cross-cutting code (uniforms, `focusables`, `viewMix`, `catalog`). Satellites: the layer is created lazily after the catalog loads → wrapper holds `inner: SatelliteLayer | null` and `attach(catalog)`; `toggleLayer("satellites", false)` hides it without disposing. Galaxy keeps its own scene/render pass: wrapper exposes `renderPass(renderer, camera)`.
**Pattern**: K4 `earth-layer.ts`.
**Constraints**: never rename/alter renderer public methods or GLSL; K1 frozen; the frame loop ordering from `E/main.ts:870-960` (now in create-engine) must be preserved (solar before earth, sats after earth, galaxy pass last).
**Ownership**: the five new layer files, `registry.ts`, `create-engine.ts`.
**Acceptance**: `npx tsc --noEmit`; `npx eslint src/engine`; guard `rg` → 0; `handle.toggleLayer("satellites", false)` hides satellites and `true` restores them with no console errors; all three views still render identically (screenshot diff against the pre-T13 build).
**HINTS**: `LayerManager` API in `src/lib/engine/layer-manager.ts`; `ILayer`/`LayerUpdateContext` in `src/types/engine.ts`; current per-frame calls (`solar.updatePositions`, `earth.update`, `sats.update`, `solar.update`, `sky.setExposure`) are listed in context map §anatomy 870-960.
**Pitfalls**: calling `layers.update` for layers whose `update` needs extra args (e.g. `solar.update({ms,camera,time,dt,earthZoom,flare})`): keep an explicit call, do not fake the context; disposing the galaxy scene twice; registering satellites before the catalog exists.
